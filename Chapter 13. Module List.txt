13.1 Purpose
This chapter provides the complete RTL module hierarchy of the processor. Modules are grouped according to the pipeline stage in which they primarily operate. For each module, the interface, functionality, and interactions with other modules are specified.

Signal Naming Convention:

Prefix			Meaning
PC_*			Program Counter signals
RS1_*, RS2_*, RD_*	Register operands and addresses
IMM			Immediate value
ALU_RESULT		Output of the ALU
TARGET_ADDRESS		PC-relative branch/JAL target
DMEM_DATA		Data read from Data Memory
WRITE_DATA		Data written back to the Register File

13.2 IF stage
1) Program Counter (PC)
Function
The Program Counter (PC) stores the address of the instruction currently being executed. On every clock cycle, it updates with the next instruction address selected by the PC Selection Multiplexer. During a pipeline stall, the PC retains its current value.

Data Inputs
Signal		Width
NEXT_PC		32

Control Inputs
Signal		Width
CLK		1
RESET		1
ENABLE		1

Data Outputs
Signal		Width
PC		32

Control Outputs
None.

Hardware Summary
Type: Sequential
Trigger: Positive-edge triggered
Reset: Asynchronous
Synthesizes to: 32-bit register with enable

2) PC + 4 Adder
Function
Computes the address of the next sequential instruction by adding 4 to the current Program Counter value.

Data Inputs
Signal		Width
PC		32

Control Inputs
None.

Data Outputs
Signal		Width
PC_4		32

Control Outputs
None.

Hardware Summary
Type: Combinational
Synthesizes to: 32-bit binary adder

3) PC Selection Multiplexer
Function
Selects the next Program Counter value based on the control signals generated by the control logic. It chooses between the sequential address (PC+4), branch target address, or jump target address.

Synthesizes to: 3-to-1 Multiplexer

Stores and retrieves program data during load and store instructions. For load instructions, the memory returns the data stored at the specified address. For store instructions, it writes the input data to the specified memory location.
