6.1 Purpose

The Arithmetic Logic Unit (ALU) is the primary computational unit of the processor. It performs arithmetic, logical, comparison, shift, address generation, and operand forwarding operations during the Execute stage. The specific operation is selected by the ALU_OP control signal generated in the Decode stage.

6.2 ALU Interface
Inputs
Signal		Width	Description
OPERAND_A	32	First ALU operand
OPERAND_B	32	Second ALU operand
ALU_OP		5	Operation select

Outputs
Signal		Width	Description

We are not using status flags (Zero, Carry, Overflow, etc.) because our branch decisions are handled by a dedicated comparator. That is one of our architectural choices.

6.6 Design Decisions
Why does the ALU perform address calculations?
Address generation is mathematically identical to integer addition. Reusing the ALU for effective address calculation avoids dedicated address-generation hardware while simplifying the datapath.

Why is PASS_B included?
The PASS_B operation allows the ALU to forward its second operand unchanged. This operation is used by the LUI instruction, enabling immediate values to be written back through the standard ALU result path instead of requiring a dedicated immediate write-back path.

Why doesn't the ALU perform branch comparisons?
Branch comparison is handled by a dedicated comparator.
Separating comparison from arithmetic allows the branch unit and ALU to operate independently and simplifies branch control logic.

Why doesn't the ALU compute branch targets?
Branch target addresses are generated by a dedicated branch target adder.
This allows arithmetic operations, branch comparison, and target address generation to be treated as separate functional units within the Execute stage.

Why are shift operations implemented in the ALU instead of using a separate shifter?
Shift operations are part of the RV32I integer instruction set and naturally belong within the integer execution unit. Incorporating the barrel shifter into the ALU keeps the datapath compact and avoids introducing an additional execution unit.
