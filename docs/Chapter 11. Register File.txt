11.1 Purpose

The Register File stores the processor's architectural registers and provides operands for instruction execution. It supports simultaneous reading of two source registers and writing of one destination register, allowing register-to-register and register-immediate instructions to execute efficiently within the five-stage pipeline.

Read

Reads are combinational.

Writes occur on the active clock edge when
REG_WRITE_EN = 1

11.5 Register x0
RISC-V defines register x0 as a hardwired zero register.
Characteristics:
Always contains zero.
Reads always return zero.
Writes are ignored.
This behavior is enforced by the Register File implementation.
If software attempts to write to x0, Then write is ignored. Register x0 is hardwired to zero and always returns zero regardless of any attempted write operation.

Register	Purpose
x0		Constant zero (hardwired)

11.6 Design Decisions

Why two read ports?
Most instructions require two source operands. Two independent read ports allow both operands to be read simultaneously during the Decode stage.

Why one write port?
The processor is single-issue and retires at most one instruction per cycle. Therefore only one register write can occur during each clock cycle.

Why are reads combinational?
Combinational reads allow operand values to become available immediately during the Decode stage, enabling execution in the following cycle without introducing additional pipeline latency.

Why are writes synchronous?
Synchronous writes ensure that register updates occur only on clock edges, preventing race conditions and maintaining predictable pipeline timing.

Why is only one write port sufficient?
The processor is a single-issue, in-order pipeline that completes at most one instruction per cycle. Consequently, only one architectural register can be updated during each write-back stage.

What would change if the processor became dual-issue?
A dual-issue processor could retire two instructions in the same cycle, requiring at least two write ports and additional read ports. The increased port count significantly increases the complexity and area of the Register File.

12.7 Architectural Register Set
The processor implements the standard RV32I architectural register set consisting of thirty-two 32-bit integer registers. Although all registers except x0 are identical in hardware, the RISC-V ABI assigns conventional software roles to each register.
