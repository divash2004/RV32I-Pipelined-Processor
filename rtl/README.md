# RTL Source

This directory contains the synthesizable Verilog RTL for the RV32I pipelined processor.

- `cpu.v` — top-level processor module
- `pipeline/` — pipeline registers
- `control/` — instruction control and hazard management
- `execution/` — ALU and execution-related logic
- `datapath/` — datapath selection and PC-related logic
- `memory/` — register file and memory modules
